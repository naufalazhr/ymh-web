# YMH Web — Yamaha Gerbang Cahaya

Static site (Cloudflare Workers Static Assets) untuk dealer resmi Yamaha Bandung & Subang.

- `site/` — seluruh halaman, CSS, JS, aset WebP
- `wrangler.toml` — konfigurasi deploy (`ymh-web`)
- `gen_motor.py` — generator 9 halaman detail motor

Deploy: `wrangler deploy` — live di https://ymh-web.naufal-vaultwork.workers.dev
